# Sprint 1 Evidence — TiendaAdmin POS

## Description

This directory contains evidence of the activities completed during Sprint 1 of the TiendaAdmin Point of Sale (POS) project.

## Objective

Document and verify the team's use of GitHub, Gitflow, project planning, and collaborative development practices.

### 1. Repository Structure
- Screenshot of the repository documentation directories.
- Evidence of the initial repository setup.

### 2. Gitflow Branches
- Screenshot showing the `main` branch.

- Screenshot showing the `feature/*` branches.

### 3. GitHub Issues
- Screenshots of created Issues.
- Assigned team members.
- Task descriptions and acceptance criteria.

### 4. GitHub Projects
- Screenshot of the project board.
- Task status and progress tracking.
- Sprint 1 backlog.

### 5. Commits
- Screenshots of commit history.
- Descriptive commit messages following team conventions.

### 6. Pull Requests
- Screenshot of Pull Requests.
- Evidence of review and approval.
- Evidence of successful merges.
