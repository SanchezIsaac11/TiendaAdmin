# POS System Requirements — TiendaAdmin

## Description

This directory contains the requirements documentation for TiendaAdmin, a Point of Sale (POS) system designed for a grocery store.

## Objective

Define the system's functional requirements, non-functional requirements, constraints, and operational needs before beginning the development phase.

## Scope

The POS system will support the following operations:

- Sales processing and payment methods.
- Product and inventory management.
- Promotions and discounts.
- Cash register opening, transactions, and closing.
- Sales history and transaction tracking.
- Sales and profit reports.
- Real-time inventory synchronization between two cash registers.
- User authentication, roles, and permissions.

## Documents

- `functional-requirements.md` — Defines the system's required features and business operations.
- `non-functional-requirements.md` — Defines performance, usability, reliability, availability, and compatibility requirements.
